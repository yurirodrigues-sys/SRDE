# UniClass
UniClass é um aplicativo para android com a função de registrar e verificar a estrutura pertencente à Ceagri II.

Principais aspectos

• Sistema de avaliação de salas e respectivos componentes 
• Cadastro e Login UFRPE
• Reportagem de falta de materiais ou equipamentos danificados
